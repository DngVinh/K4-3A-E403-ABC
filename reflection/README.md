# Individual reflection files

Theo cấu trúc repo của đề bài, mỗi thành viên cần thêm một file reflection cá
nhân trước CP6. File reflection phải do chính thành viên viết, không dùng một
bản tổng hợp thay cho suy nghĩ cá nhân.

## Tên file đề xuất

- `vinh.md`
- `hieu.md`
- `nguyen.md`
- `vu.md`

## Nội dung tối thiểu mỗi file

1. Phần việc có tên mình và bằng chứng tương ứng.
2. Một quyết định mình đã thay đổi sau khi có bằng chứng.
3. Một điều chưa hoàn tất hoặc rủi ro còn lại.
4. Điều mình sẽ làm khác nếu có thêm thời gian.

Repo đã có bốn reflection tương ứng: `vinh.md`, `hieu.md`, `nguyen.md` và
`vu.md`. Theo xác nhận của nhóm ngày 18/09/2026, cả bốn thành viên đã đọc,
chỉnh theo trải nghiệm cá nhân và xác nhận nội dung ở cuối file.
