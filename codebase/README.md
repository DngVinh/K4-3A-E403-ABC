# CP2 clickable prototype — VLearn FixFirst

Prototype này minh họa lát cắt D2:

`attempt → diagnose → hint → self-correct → explain-back`

## Cách chạy

Mở `index.html` bằng trình duyệt. Không cần cài dependency hoặc API key.

## Kịch bản demo

1. Chọn concept **Tokenization**.
2. Bấm **Bắt đầu làm bài**.
3. Giữ câu trả lời mẫu và bấm **Nộp để xem chẩn đoán**.
4. Xem giả định sai, hint và citation fixture.
5. Bấm qua bước tự sửa, giải thích lại và hoàn tất.

## Phạm vi CP2

- Đây là mock dùng fixture, chưa gọi AI thật.
- Citation đang được đánh dấu là mẫu; sẽ thay bằng mã đoạn transcript/slide đã xác minh khi làm CP3.
- Mục tiêu CP2 là cho thấy flow chính bấm được từ đầu đến cuối.
